# FPGA Verilog 离线备赛库

面向嵌赛 FPGA 赛道能力评测的 Windows 桌面练习库，包含 529 个题目入口、199,999 个练习变式和 788 个知识条目。

## 下载与运行

从 [GitHub Releases](https://github.com/Beiminyou1/VerilogHDL-/releases) 下载 Windows x64 便携版 ZIP。解压整个文件夹，双击 `FPGA-Verilog-备赛库.exe`。

程序可离线运行。在题库中选中题目后，可按参数和任务切换变式，也可输入完整题号直接打开。答案区附参考 Verilog、逐行讲解和仿真波形。
